# Visual Isnad hadith source evaluation

## Recommendation

**Best single source for the current application: the existing Visual Isnad read model.** It provides the reviewed Bukhari references, bilingual text, explicit transmission handling, and editor workflows in one offline application. It also has significant unresolved and missing routes and must not be treated as an exhaustive scholarly graph.

**Best standalone expansion source: Hadith Knowledge Graph.** It has the strongest verified structured isnad, narrator and cross-collection data. Its Arabic-first edition differs from Visual Isnad's numbering, its Bukhari routes can terminate at a Companion even for a marfūʿ report, and it cannot supply the English reader by itself.

**Best combination:** retain Visual Isnad for reviewed content and identity; use KG for adjudicated route and narrator enrichment; acquire a cleared English translation and use the official Sunnah reference interface where authorization permits. Use Fawaz Arabic as an offline concordance check, mhashim6 commentary for resolving names and textual variants, and Dorar for editorial discovery. Avoid provider dependency in core reads.

### Secondary candidates

- **MuslimScholars.info is already used.** The project has a cached biography JSON, primary rawis CSV, and a reviewed supplement. The profile URL for Ibn ʿUlayya responded to a page request, but this audit did not establish a public API, current bulk license, or live profile-content parity. Preserve citation and reviewed overlays. [Profile](https://muslimscholars.info/manage.php?ID=20208&submit=scholar)
- **Dorar is new to this evaluation.** A curl GET for `إنما الأعمال بالنيات` returned 200 and JSON containing HTML results. The Python probe received 403 in this environment. Useful Arabic search and source/grading leads for reviewers. Bulk rights, quotas, fragments and stability are not established. [Dorar](https://dorar.net/hadith)
- **HadeethEnc is new.** Curl category and paginated listing probes returned 200 with categories, titles and language lists. Python category probe got 403. Consider for curated multilingual explanation. No evidence of Bukhari edition completeness or ordered narrator coverage from those endpoints. [HadeethEnc](https://hadeethenc.com/en)
- **Gading Hadith API is new.** A Bukhari item probe returned 503 in this environment. Treat as a lead, with no scored data claim. [Repository](https://github.com/gadingnst/hadith-api)

## Bukhari benchmark

Read-only measurement compared exact normalized full text independently of IDs. It strips combining marks, control marks, elongation and punctuation for matching and retains raw source text for display. Repeated text produces multiple candidates. A near match or an agreed number alone cannot authorize a crosswalk. KG candidates use shared three-token phrases, then sequence similarity over normalized Arabic and manual checks on named anchors.

| Dataset | Rows | Distinct native IDs | Visual references matching any exact normalized Arabic | Visual references matching any exact normalized English |
|---|---:|---:|---:|---:|
| Visual corrected | 7,277 | 7,277 | Baseline | Baseline |
| KG Bukhari | 7,031 | 7,031 | 114 | Not supplied |
| mhashim6 plain and vocalized (each) | 7,008 | 7,008 | 1,640 | Not supplied |
| Jaguar16 Bukhari | 7,252 | 7,252 | 7,252 | 7,247 |
| Fawaz Arabic / English (each) | 7,589 | 7,589 | 7,266 | 5,790 |

The releases differ in how reports are split, numbered and transcribed. The Fawaz editions each include nine empty texts; the Arabic edition contains 297 repeated normalized text groups, and Jaguar contains eight. The counts do not establish the number of unique historical reports. Jaguar's similarity is consistent with shared Sunnah text ancestry and is not independent corroboration. Exact comparison undercounts legitimate edition variants and cannot score translation accuracy.

The 10 anchors were 1, 5, 15, 32, 74, 94, 188, 765, 1067 and 7478. The eight randomly drawn references were 6770, 4648, 6122, 5006, 4211, 6722, 742 and 2858 using seed **17154** after sorting the source refs. Machine results preserve each sample and candidate. Jaguar and Fawaz Arabic supplied exact normalized Arabic for all 18 sample references. Hadith 94 maps to 92 in mhashim6 and 93 in KG. Hadith 765 maps to 723 in mhashim6 and 726 in KG. Hadith 15 requires preserving Ibn ʿUlayya and both ways through Anas. Hadith 188 had no Visual route and no confident KG crosswalk. Hadith 32 has routes in Visual and no route for the leading KG text candidate. Hadith 7478 illustrates where KG can preserve an additional narrator in an embedded dialogue. See the [Knowledge Graph audit](knowledge-graph-audit.md) for the path-level anchors.
